# 🚀 Nakul Chauhan — Portfolio

A modern, responsive developer portfolio built with **React** and **Vite**, featuring glassmorphism UI, smooth animations, and a dark-themed design.

## 🔗 Live Preview

👉 **[nakulchauhan003.github.io/NakulChauhanPortfolio](https://nakulchauhan003.github.io/NakulChauhanPortfolio/)**

## ✨ Features

- **Animated Hero Section** — Typing effect, gradient text shimmer, glowing profile image
- **Glassmorphism Cards** — Frosted glass effects with mouse-tracking spotlight
- **Interactive Skills Grid** — Hover animations on tech stack tags
- **Project Showcase** — Auto-numbered cards with tag badges
- **Experience Timeline** — Gradient vertical line with glowing dots
- **Certificate Gallery** — Image-based gallery with zoom-on-hover
- **Hackathon Highlights** — Clean list-style layout
- **Contact Section** — Glowing container with social links
- **Fully Responsive** — Optimized for desktop, tablet, and mobile
- **Custom Scrollbar** — Themed to match the UI

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| React 19 | UI Components |
| Vite 7 | Build Tool & Dev Server |
| Vanilla CSS | Styling (no frameworks) |
| Google Fonts | Typography (Outfit, Inter, Fira Code) |

## 📦 Getting Started

```bash
# Clone the repo
git clone https://github.com/nakulchauhan003/nakul-chauhan-portfolio.git

# Navigate to the project
cd nakul-chauhan-portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

The site will be available at `http://localhost:5173/`

## 🏗️ Build for Production

```bash
npm run build
```

The output will be in the `dist/` folder, ready for deployment.
